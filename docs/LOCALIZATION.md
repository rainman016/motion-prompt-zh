# 本地化维护说明

## 数据、语言与配置

六个 `packs/*/meta.json` 为内容源，包标题、子分类和全部元素的 `name / meaning / ask / summary / spec / use` 增加完整 `zh-Hans`。英文、日文、tags、编号、slug、排序保留。可选 `aliases` 为按语言编码组织的字符串数组，仅补充搜索，不替代英文 tags。

`assets/language.js` 统一优先级：有效 URL → 保存偏好 → `zh-Hans`。`zh` 仅为输入别名，不生成资源目录。网页和 API 的 Prompt 使用构建脚本内同一个函数，以及配置的规范站点地址；网页资源请求与分享使用当前 HTTP 地址，支持本地及 Pages 子路径。公开发布前 Prompt 的规范站点链接尚不可用，本地详情的相对资源链接仍可读取。

`site.config.json` 为唯一部署配置源，构建同步网页和 Skill 配置、元数据、插件地址及 API。原作者与来源链接不改向。原英文/日文历史文档保留原站链接；本版安装发布以中文 README 为准。

中文版可安装技能位于 `skills/motion-prompt-zh/`，名称为 `motion-prompt-zh`；`skills/motion-prompt/scripts/motion-prompt.mjs` 仅为旧命令兼容入口。CLI 与构建共享 `scripts/config.mjs` 的 URL 解析，源码仓库读取根配置；独立安装读取构建生成的 `scripts/site-config.json`。本地源码优先于默认远程 API，显式 `MOTION_PROMPT_BASE` 优先于两者；缺中文资料会报错，备用来源及缓存会明确显示。增量测试见 [Skill 集成验收](SKILL-INTEGRATION.md)。

本次不修改六个 `pack.js` 和 `assets/runtime.js`。内部文字参与测量、切片、遮罩及固定坐标排版，统一替换可能改变构图和节奏，所以保留原始示例字样；卡片和详情提供完整中文解释。

| camera 025–048 | 运镜读数、HANDHELD / FREEZE / SHOT、日文轨道标签 | 原始测量、对照和时间线布局 |
| ui 049–072 | 日文菜单、按钮、表单、提示与空状态 | 固定排版与模拟光标路径 |

| motion2 121–144 | HELLO / WORLD / WAVE TEXT / MOTION / OCEAN、日文部件标签 | 字符数、测量、遮罩和分解引线 |

`make-your-own/` 的历史双语视频、速查图和独立创作工具原样保留，未声称这些历史成品已有中文版。开发预览页补充中文外层信息；上游生成工具和贡献文档保留原文，本版差异由中文说明补充。
