Motion Prompt #126

どういうものか: 決めた曲線に沿って動く
見本で起きること: 点線の道に沿って、紙飛行機が向きを変えながら進み、途中で宙返りする。
仕様:
- 4.7秒で1回、左の画面外から右の画面外へ。道は x = 270 + 112θ − 150·sinθ、y = 106 − 74·cosθ（θ = −π→π）。中央の上で輪になる（宙返り）
- θ は時間に比例して進める（道の上の速さは一定でない。輪の部分はゆっくり見える）
- 紙飛行機は道の向きに回す: 角度 = atan2(74·sinθ, 112 − 150·cosθ)
- 道は点線（線幅6・間隔2/15）で先に見せておく。通ったあとにミントの線を24区間（θで0.03ずつ）残し、後ろほど細く薄くする
使いどころ: 飛ぶ物・走る車・地図の上の移動など、決まった道筋を通らせたいとき。
