// パルス / Pulse
// パック: motion2 (モーショングラフィックスの演出 第2弾) · element 05 · カテゴリ: 動きのテクニック
// 何が起きるか: ハートが鼓動のように、ドクン・ドクンと大きさを脈打たせ、輪が広がる。
// 動きの仕様:
//   - コーラルのハート。1.175秒に1拍（4.7秒に4拍）。1拍は「ドクン・ドクン」の2段
//   - 拡大率 = 1 + 0.26·G(0.2秒, 幅0.065) + 0.15·G(0.44秒, 幅0.07)。G = e^(−((t − 中心)÷幅)²)（急にふくらんで、すぐ戻る山）
//   - ハートの輪郭線を2つ広げる: 0.16秒と0.40秒から、0.8秒で拡大率1.2→2.4（easeOut・3乗）
//   - 輪は広がりながら不透明度0.75→0（2つ目は60%の濃さ）、線幅8.5→1.5px
// 使いどころ: 「いいね」・録音中・ライブ配信中・押してほしいボタンなど、生きている感じや注目を出したいとき。
// タグ: pulse, heartbeat, throb, scale, loop, like, attention
// サイズ: 539x208 px · 1周: 4.7 s
// Needs: kit motion2 -> https://rainman016.github.io/motion-prompt-zh/api/v1/kit/motion2.js
// 動く見本: https://rainman016.github.io/motion-prompt-zh/?lang=ja#125
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 05
// 05 パルス（ハートが鼓動のように、ドクン・ドクンと大きさを脈打たせる）
CELLS[4] = (k, w, h, u) => {
  stage(k);
  const T = CYC / 4, lu = mod(u, T), X = w / 2, Y = h / 2 + 10;
  const g = (c, s) => Math.exp(-Math.pow((lu - c) / s, 2));
  const b = 0.26 * g(0.2, 0.065) + 0.15 * g(0.44, 0.07) + 0.26 * Math.exp(-Math.pow((lu - T - 0.2) / 0.065, 2));
  for (const [t0, s] of [[0.16, 1], [0.4, 0.6]]) {
    const q = P(lu, t0, t0 + 0.8); if (q <= 0 || q >= 1) continue;
    k.save(); k.translate(X, Y); const sc = 1.2 + 1.2 * eOut(q); k.scale(sc, sc); heartPath(k, 44);
    k.strokeStyle = C.coral; k.globalAlpha = (1 - q) * 0.75 * s; k.lineWidth = (7 * (1 - q) + 1.5) / sc; k.stroke(); k.restore();
  }
  k.globalAlpha = 1;
  k.save(); k.translate(X, Y); k.scale(1 + b, 1 + b); heartPath(k, 44); k.fillStyle = C.coral; k.fill();
  k.fillStyle = 'rgba(255,255,255,.75)'; k.beginPath(); k.ellipse(-30, -28, 9, 6, -0.7, 0, 7); k.fill(); k.restore();
};
