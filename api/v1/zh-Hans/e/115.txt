// 黑白摄影 / Black and white
// 分类包: photo (摄影光线与风格) · element 19 · 子分类: 色调与后期风格
// 动画表现: 同一风景逐渐褪色，太阳和人物受光边变灰，只靠亮度区分形状。
// 运动规格:
//   - 场景 3：左侧半身像的头部中心 x 140、y 82、半径 28 px；右侧有山丘、房屋、树与太阳，太阳 x 432、y 54、半径 15 px。
//   - 每种颜色按亮度 0.2126R + 0.7152G + 0.0722B 转灰，再以 140 为中心将对比放大 ×1.25。
//   - 例如人物 #4D5A75 → 约 #4D4D4D，太阳 #F5A524 → 约 #B5B5B5。
//   - 效果在 0.4 秒至 1.4 秒进入，保持到 4.0 秒，在 4.8 秒前消失；每轮 5 秒，三次缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
// 适用场景: 适合经典、恒久的观感，或让形状、光线、表情优先于颜色。
// 标签: black and white, monochrome, b&w, grayscale, desaturated, classic
// 尺寸: 539x208 px · 周期: 5 s
// 依赖: kit photo -> https://rainman016.github.io/motion-prompt-zh/api/v1/kit/photo.js
// 动画演示: https://rainman016.github.io/motion-prompt-zh/?lang=zh-Hans#115
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D，调用方已清空并包裹 save/restore；w、h 为尺寸，u 为 [0, cycle) 内的秒数。画面仅由 u 决定。
// 以下为元素代码，CELLS、常量和辅助函数位于共享 kit 中。

// @element 19
// モノクロ: 色を抜き、明るさだけで見せる（コントラストを少し強める）
CELLS[18] = cell((k, u) => {
  const a = env(u);
  const GRAY = mapPal(BASE, c => { const g = clamp((lum(c) - 140) * 1.25 + 140, 0, 255); return toHex([g, g, g]); });
  stageLand(k, pal(BASE, GRAY, a));
});
