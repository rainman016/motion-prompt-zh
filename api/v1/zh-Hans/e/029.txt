// 跟拍镜头 / Tracking shot
// 分类包: camera (镜头运动与剪辑) · element 05 · 子分类: 镜头运动
// 动画表现: 相机与行人同速横移，人物始终居中，近处柱子更快掠过。
// 运动规格:
//   - 相机以恒定 1.7 m/s 向右移动，在 4.7 秒内 x = -4.0 m → +4.0 m；高 1.3 m，正向取景，无缓动。
//   - 人物的 x 与相机一致，距离 7.5 m，始终居中；手臂与腿按 sin(u×7)×0.42 rad 摆动。
//   - 视差：纵深 4 m、间隔 1.6 m 的柱子最快向左掠过，其次是树，再是 48 m 远的建筑；山几乎不动。
//   - 右上角显示“→ 1.7m/s”。
//   - 每 4.7 秒跳回起点；柱子和地面网格在接缝处对齐，背景建筑和树会跳变。
// 适用场景: 适合跟随行走或奔跑的主体，兼顾动作与运动感。
// 标签: tracking, tracking shot, follow, truck, lateral, sideways, parallax, walk
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://rainman016.github.io/motion-prompt-zh/api/v1/kit/camera.js
// 动画演示: https://rainman016.github.io/motion-prompt-zh/?lang=zh-Hans#029
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D，调用方已清空并包裹 save/restore；w、h 为尺寸，u 为 [0, cycle) 内的秒数。画面仅由 u 决定。
// 以下为元素代码，CELLS、常量和辅助函数位于共享 kit 中。

// @element 05
// 05 トラッキング: 人物と並んで横移動（手前ほど速く流れる）
CELLS[4] = shot((k, w, h, u) => {
  const x = (u - CYC / 2) * 1.7;
  const fgp = []; for (let i = -12; i <= 12; i++) fgp.push([i * 1.6, 4]);
  world(k, w, h, cam({ x, y: 1.3 }), { person: { x, z: 7.5, walk: u * 7 }, fg: fgp });
  return '→ 1.7m/s';
});
