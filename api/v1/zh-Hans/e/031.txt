// 升降镜头上升 / Crane up
// 分类包: camera (镜头运动与剪辑) · element 07 · 子分类: 镜头运动
// 动画表现: 相机一边上升一边俯拍，逐渐从上方看向人物。
// 运动规格:
//   - 机位从 1.4 m 升至 9 m，同时向前移动 0 m → 1.5 m。
//   - 向下俯仰以保持前方 8 m 的人物在画面内；俯仰 = -0.86 × atan2(height - 1.0, 8 - forward)，约 -2.5° → -44°。
//   - 0.5 秒至 3.4 秒运动，持续 2.9 秒，采用三次缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
//   - 人物不动，随机位上升变小；地面网格铺满画面，地平线从顶部离开。
//   - 3.4–4.2 秒停留，最后 0.5 秒交叉淡化回起点，每轮 4.7 秒。
//   - 右上角显示高度，↑ 1.4m → ↑ 9.0m。
// 适用场景: 适合场景结尾拉开与人物的距离，或揭示环境规模。
// 标签: crane, crane up, jib, boom up, rise, high angle, camera move
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://rainman016.github.io/motion-prompt-zh/api/v1/kit/camera.js
// 动画演示: https://rainman016.github.io/motion-prompt-zh/?lang=zh-Hans#031
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D，调用方已清空并包裹 save/restore；w、h 为尺寸，u 为 [0, cycle) 内的秒数。画面仅由 u 决定。
// 以下为元素代码，CELLS、常量和辅助函数位于共享 kit 中。

// @element 07
// 07 クレーンアップ: カメラが上昇し、見下ろしになる
CELLS[6] = shot(camCell((k, w, h, p) => {
  const y = lerp(1.4, 9, p), z = lerp(0, 1.5, p);
  world(k, w, h, cam({ y, z, pitch: -0.86 * Math.atan2(y - 1.0, 8 - z) }), { person: { z: 8 } });
}, p => `↑ ${lerp(1.4, 9, p).toFixed(1)}m`));
