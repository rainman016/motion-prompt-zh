// 环绕镜头 / Orbit (Arc shot)
// 分类包: camera (镜头运动与剪辑) · element 06 · 子分类: 镜头运动
// 动画表现: 相机沿圆周绕主体移动，人物保持居中，身后的树与建筑横向掠过。
// 运动规格:
//   - 相机以位于前方 9 m 的人物为圆心，沿半径 6 m 的圆移动；角度 -0.95 rad → +0.95 rad，即 -54° → +54°，总计约 109°。
//   - 始终朝向圆心，偏航角 = -angle；高 1.7 m，俯仰固定为 -0.07 rad，约向下 4°。
//   - 0.5 秒至 3.6 秒运动，持续 3.1 秒，采用三次缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
//   - 人物不动；脸上的白点随角度横移；地面有半径 1.3 m 的虚线圆。
//   - 12 棵树均匀排列在半径 10 m 的圆周上，相机环绕时从人物背后经过。
//   - 3.6–4.2 秒停留，最后 0.5 秒交叉淡化复位；右上角显示 -54° → +54°。
// 适用场景: 适合立体展示人物或产品，也可突出登场与关键时刻。
// 标签: orbit, arc shot, circle, 360, rotate around, revolve, camera move
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://rainman016.github.io/motion-prompt-zh/api/v1/kit/camera.js
// 动画演示: https://rainman016.github.io/motion-prompt-zh/?lang=zh-Hans#030
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D，调用方已清空并包裹 save/restore；w、h 为尺寸，u 为 [0, cycle) 内的秒数。画面仅由 u 决定。
// 以下为元素代码，CELLS、常量和辅助函数位于共享 kit 中。

// @element 06
// 06 オービット: 被写体を中心に円を描いて回り込む
CELLS[5] = shot(camCell((k, w, h, p) => {
  const a = lerp(-0.95, 0.95, p), R = 6, P0 = [0, 0, 9];
  const c = cam({ x: P0[0] + Math.sin(a) * R, z: P0[2] - Math.cos(a) * R, yaw: -a, y: 1.7, pitch: -0.07 });
  world(k, w, h, c, {
    person: { z: 9, face: a }, ring: [0, 9, 10], buildings: true, trees: false,
    after: (kk, cc) => { kk.strokeStyle = C.blueM; kk.lineWidth = 2; kk.setLineDash([5, 5]); kk.beginPath(); for (let i = 0; i <= 48; i++) { const b = i / 48 * Math.PI * 2; const q = proj(cc, Math.sin(b) * 1.3, 0, 9 + Math.cos(b) * 1.3); i ? kk.lineTo(q.x, q.y) : kk.moveTo(q.x, q.y); } kk.stroke(); kk.setLineDash([]); }
  });
}, p => `${Math.round(lerp(-0.95, 0.95, p) * 57.3)}°`.replace(/^(\d)/, '+$1'), 0.5, 3.6));
