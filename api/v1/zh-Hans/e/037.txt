// 慢动作 / Slow motion
// 分类包: camera (镜头运动与剪辑) · element 13 · 子分类: 拍摄风格与时间
// 动画表现: 固定机位下，人物缓慢跃起落下，树叶缓慢飘落，整个动作被拉长。
// 运动规格:
//   - 机位完全固定，高 1.3 m；只有主体运动。
//   - 人物距离 7 m，一次跳跃持续 3.8 秒，从 0.5 秒到 4.3 秒；高度 = 4q(1-q)×1.1 m，为峰值 1.1 m 的抛物线，q 随时间线性变化。
//   - 空中双臂举起；起跳前静止 0.5 秒，落地后静止 0.4 秒。
//   - 9 片叶子在 4.7 秒内从 3.4 m 高处旋转落地，每片错开周期的 1/9。
//   - 右上角显示“120fps ×0.25”，播放时长拉长 4×。
//   - 无停留、无交叉淡化，每 4.7 秒无缝循环。
// 适用场景: 适合观察短暂动作或表情，也可强化情绪高潮。
// 标签: slow motion, slow-mo, slomo, high frame rate, 120fps, time stretch, jump
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://rainman016.github.io/motion-prompt-zh/api/v1/kit/camera.js
// 动画演示: https://rainman016.github.io/motion-prompt-zh/?lang=zh-Hans#037
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D，调用方已清空并包裹 save/restore；w、h 为尺寸，u 为 [0, cycle) 内的秒数。画面仅由 u 决定。
// 以下为元素代码，CELLS、常量和辅助函数位于共享 kit 中。

// @element 13
// 13 スローモーション
CELLS[12] = shot((k, w, h, u) => {
  const q = P(u, 0.5, 4.3);
  world(k, w, h, cam({ y: 1.3 }), { person: { z: 7, y: jumpY(q), armUp: q > 0 && q < 1 }, extra: leaves(u, 1) });
  return '120fps ×0.25';
});
