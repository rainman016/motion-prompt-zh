// 运动规格:
//   - 机位固定，高 1.5 m；仅偏航，-0.32 rad → +0.32 rad，即 -18° → +18°，总计约 37°。
//   - 0.5 秒至 3.4 秒转动，持续 2.9 秒，采用三次缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
//   - 人物高约 1.8 m，在前方 8 m 处静止，画面中从右向左滑动。
//   - 无视差：山、建筑、树和人物以相同角度偏移；539×208 卡片的焦距为 330 px。
//   - 3.4–4.2 秒停留，最后 0.5 秒交叉淡化回起点，每轮 4.7 秒。
//   - 右上角以整数度数显示角度，-18° → +18°。
// 适用场景: 适合展示宽阔环境，或将注意力从画面一侧引向另一侧。
// 标签: pan, panning, yaw, rotate, horizontal, camera move, reveal
// 尺寸: 539x208 px · 周期: 9.4 s

  p => `${Math.round(lerp(-0.32, 0.32, p) * 57.3)}°`.replace(/^(\d)/, '+$1')));
