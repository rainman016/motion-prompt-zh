// 变焦放大 / Zoom in
// 分类包: camera (镜头运动与剪辑) · element 04 · 子分类: 镜头运动
// 动画表现: 相机不动，只增加焦距，因此整幅画面按同一比例放大。
// 运动规格:
//   - 位置和朝向固定，高 1.5 m；仅焦距变化，330 px → 1200 px，显示为 24mm → 87mm，约 3.6×。
//   - 指数插值 f = 330 × (8/2.2)^p；p 在 0.5 秒至 3.4 秒采用三次缓入缓出，持续 2.9 秒。
//   - 人物在前方 8 m 静止，最终尺寸与 03 镜头推进相同，约 3.6×。
//   - 无视差：前景柱、岩石、人物、建筑、山都按同一比例缩放，遮挡关系不变。
//   - 3.4–4.2 秒停留，最后 0.5 秒交叉淡化回起点，每轮 4.7 秒。
//   - 右上角以 mm 显示焦距，24mm → 87mm。
// 适用场景: 适合不移动机位地突出某个位置；比镜头推进更平面、更有观察感。
// 标签: zoom, zoom in, focal length, lens, magnify, telephoto, camera move
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://rainman016.github.io/motion-prompt-zh/api/v1/kit/camera.js
// 动画演示: https://rainman016.github.io/motion-prompt-zh/?lang=zh-Hans#028

// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D，调用方已清空并包裹 save/restore；w、h 为尺寸，u 为 [0, cycle) 内的秒数。画面仅由 u 决定。

// @element 04
// 04 ズームイン: 位置は固定・焦点距離だけ伸びる（全体が同じ比率で拡大）

  p => mm(F0 * Math.pow(8 / 2.2, p))));
