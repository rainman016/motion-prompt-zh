// 滑动变焦（希区柯克变焦） / Dolly zoom (Vertigo)
// 分类包: camera (镜头运动与剪辑) · element 08 · 子分类: 镜头运动
// 动画表现: 相机后退，同时按相同比例变焦放大；人物大小不变，背景却向前逼近。
// 运动规格:
//   - 前方 8 m 处为人物，相机到人物的距离 d 从 3.2 m → 8 m，后退 4.8 m；机位高 1.3 m。
//   - 焦距 f = 330 × d/8 px，即 132 px → 330 px，显示 10mm → 24mm；保持距离 ÷ 焦距不变。
//   - 0.5 秒至 3.4 秒运动，持续 2.9 秒，采用三次缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
//   - 人物静止，画面高度不变；头顶 1.8 m 和脚底处有宽 160 px 的蓝色虚线，标示恒定尺寸。
//   - 48 m 远的建筑放大约 2.2×，山约 2.4×，向人物身后逼近；人物前方地面缩小。
//   - 3.4–4.2 秒停留，最后 0.5 秒交叉淡化回起点，每轮 4.7 秒。
// 适用场景: 适合表现领悟、不安或震惊的瞬间。
// 标签: dolly zoom, vertigo, zolly, push pull, background stretch, unease, camera move
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://rainman016.github.io/motion-prompt-zh/api/v1/kit/camera.js
// 动画演示: https://rainman016.github.io/motion-prompt-zh/?lang=zh-Hans#032
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D，调用方已清空并包裹 save/restore；w、h 为尺寸，u 为 [0, cycle) 内的秒数。画面仅由 u 决定。
// 以下为元素代码，CELLS、常量和辅助函数位于共享 kit 中。

// @element 08
// 08 ドリーズーム: 人物の大きさは一定、背景だけ伸び縮み
CELLS[7] = shot(camCell((k, w, h, p) => {
  const d = lerp(3.2, 8, p), f = F0 * d / 8 * 1.0;
  const c = cam({ z: 8 - d, f, y: 1.3 });
  world(k, w, h, c, {
    person: { z: 8 }, trees: true,
    after: (kk, cc) => { const top = proj(cc, 0, 1.8, 8).y, bot = proj(cc, 0, 0, 8).y; kk.strokeStyle = C.blue; kk.lineWidth = 1.6; kk.setLineDash([6, 5]); kk.beginPath(); kk.moveTo(-80, top); kk.lineTo(80, top); kk.moveTo(-80, bot); kk.lineTo(80, bot); kk.stroke(); kk.setLineDash([]); }
  });
}, p => mm(F0 * lerp(3.2, 8, p) / 8)));
