// 跳切 / Jump cut
// 分类包: camera (镜头运动与剪辑) · element 17 · 子分类: 剪辑与转场
// 动画表现: 机位和构图不变，人物位置与时钟跳变，跳过同一场景中的时间。
// 运动规格:
//   - 直接硬切，无特效，0 帧过渡；共 5 个镜头，每个 0.94 秒，即 4.7 秒 ÷ 5。
//   - 各镜头机位和构图完全一致，高 1.4 m、正向取景，背景不移动任何像素。
//   - 人物距离 7 m，横向位置依次跳为 -2.2 m → 1.4 m → -0.4 m → 2.4 m → 0.6 m；镜头 2 和 4 中双臂举起。
//   - 每个镜头内人物静止，只通过位置和姿态差异体现跳变。
//   - 右上角时钟依次为 10:02 → 10:17 → 10:41 → 11:06 → 11:30，表明同一地点的时间被跳过。
//   - 镜头 5 直接切回镜头 1。
// 适用场景: 适合压缩讲话或工作中的停顿、提升节奏，或快速表现时间流逝。
// 标签: jump cut, cut, time skip, same framing, vlog, ellipsis, edit
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://rainman016.github.io/motion-prompt-zh/api/v1/kit/camera.js
// 动画演示: https://rainman016.github.io/motion-prompt-zh/?lang=zh-Hans#041
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D，调用方已清空并包裹 save/restore；w、h 为尺寸，u 为 [0, cycle) 内的秒数。画面仅由 u 决定。
// 以下为元素代码，CELLS、常量和辅助函数位于共享 kit 中。

// @element 17
// 17 ジャンプカット（同じ画角で人物の位置と時刻だけ飛ぶ）
CELLS[16] = shot((k, w, h, u) => {
  const shots = [[-2.2, 0], [1.4, 1], [-0.4, 0], [2.4, 1], [0.6, 0]];
  const times = ['10:02', '10:17', '10:41', '11:06', '11:30'];
  const i = Math.min(4, Math.floor(u / (CYC / 5)));
  const [x, arm] = shots[i];
  world(k, w, h, cam({ y: 1.4 }), { person: { x, z: 7, armUp: !!arm } });
  return times[i];
});
