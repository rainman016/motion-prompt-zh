Motion Prompt #044

效果解释：前后两个镜头逐渐叠化
动画表现：下一画面叠在当前画面上，透明度逐渐增加至完全替代；中途两者同时可见。
实现规格与关键运动参数：
- 转场持续 1.5 秒，从 1.5 秒到 3.0 秒；后画面透明度 0 → 100%。
- 采用二次缓入缓出，约 cubic-bezier(0.45,0,0.55,1)，于 2.25 秒达到 50%。
- 前画面在底层保持完全不透明，后画面绘制在上方，不先淡出前画面。
- 两画面机位均固定，A 高 1.4 m，B 高 1.6 m、俯仰 +0.1 rad；主体也静止。
- 0–1.5 秒仅显示前画面，3.0–4.7 秒仅显示后画面。
- 每 4.7 秒交替 A→B 与 B→A，往返 9.4 秒；右上角显示“A → B”或“B → A”。
适用场景：适合柔和地表现时间或地点变化，也可进入回忆。
