Motion Prompt #126

效果解释：沿预先定义的曲线移动
动画表现：纸飞机沿点线路径飞行，随路径转向，中途绕一个环。
实现规格与关键运动参数：
- 每 4.7 秒从左画外到右画外一轮；路径 x = 270 + 112θ − 150·sinθ，y = 106 − 74·cosθ，θ = −π→π，在顶部中央形成环。
- θ 与时间成正比，因此沿路径速度不恒定，绕环时看起来更慢。
- 飞机按路径方向转动，角度 = atan2(74·sinθ, 112 − 150·cosθ)。
- 路径提前显示为点线，宽 6、虚线节距 2/15；后方跟随24 段薄荷色拖尾，每段 θ 差 0.03，越靠后越细越淡。
适用场景：适合飞行物、汽车或地图行程等需要固定路线的运动。
