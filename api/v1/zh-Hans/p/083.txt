请使用“光标跟随（Cursor follower）”，属于“落地页与网页动效”。
Motion Prompt #083

效果解释：图形稍有延迟地跟随鼠标
动画表现：光标在页面中移动，橙色圆稍微滞后地跟随。
实现规格与关键运动参数：
- 光标轨迹 x = 255 + 175·sin(2πt/4.8)，y = 86 + 46·sin(4πt/4.8)，为横向八字，每 4.8 秒一圈。
- 跟随圆半径 17、橙色、透明度 0.88，绘制在光标下方。
- 每帧按 60 fps 计算，走完剩余距离的 12%，即 x += (cursor x − x) × 0.12。
- 箭头光标始终可见。
适用场景：适合品牌站和作品集，增加互动与趣味。
