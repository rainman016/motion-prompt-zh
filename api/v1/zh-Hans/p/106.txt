Motion Prompt #106

效果解释：上下模糊，让真实场景像微缩模型
动画表现：街景上下模糊，只有中间道路、汽车和小人物清晰，使街道像模型。
实现规格与关键运动参数：
- 街角有建筑、树和路灯，道路 y 132–162，无前景大人物；四个小人物高 23–26 px，站在人行道上，脚底 y 172；汽车每 5 秒从 x −60 行驶到 600。
- 清晰带为 y 66–176。
- 模糊：y 0–42 与 y 190–208 从 0 → 7 px，y 42–66 与 y 176–190 从 0 → 3 px。
- 清晰带边缘有虚线，线段 6 px、间隔 5 px，颜色 #8E8E93、透明度 75%。
- 效果在 0.4 秒至 1.4 秒进入，保持到 4.0 秒，在 4.8 秒前消失；每轮 5 秒，三次缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
适用场景：适合把城市或活动现场表现为玩具模型世界。
