Motion Prompt #116

效果解释：用两种颜色分别映射暗部和亮部
动画表现：同一风景的颜色被替换为两色之间的层次，暗部靛蓝、亮部粉色。
实现规格与关键运动参数：
- 场景 3：左侧半身像的头部中心 x 140、y 82、半径 28 px；右侧有山丘、房屋、树与太阳，太阳 x 432、y 54、半径 15 px。
- 暗端颜色 #1F2A5C，亮端颜色 #FF9FB2。
- 按各颜色亮度 L 计算 t = ((L − 70) / 180)^2.4，再以 t 混合两色，拉开亮部层次。
- 效果在 0.4 秒至 1.4 秒进入，保持到 4.0 秒，在 4.8 秒前消失；每轮 5 秒，三次缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
适用场景：适合用品牌色统一海报、音乐封面或社交图片。
