请使用“双重曝光（Double exposure）”，属于“摄影光线与风格”。
Motion Prompt #120

效果解释：将两张照片叠合在同一画面
动画表现：背景变白，山丘、房屋、树和太阳缩小后只出现在半身像轮廓内部。
实现规格与关键运动参数：
- 场景 3：左侧半身像的头部中心 x 140、y 82、半径 28 px；右侧有山丘、房屋、树与太阳，太阳 x 432、y 54、半径 15 px。
- 半身像外部背景为白色 #FFFFFF。
- 轮廓内使用同一风景的 0.7× 缩小版，太阳位于头部右上，山脊横过颈部。
- 内部颜色：天空 #D3DBE6，山丘 #9AA8BD 和 #76869F，地面 #55647E，树 #3F4C66。
- 按效果强度将双重曝光版本叠在原图上。
- 效果在 0.4 秒至 1.4 秒进入，保持到 4.0 秒，在 4.8 秒前消失；每轮 5 秒，三次缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
适用场景：适合将人物与地点、回忆或内心世界联系起来的海报和封面。
