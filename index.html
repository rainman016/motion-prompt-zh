通过 Skill 安装

在终端运行下方命令。安装后，告诉 AI“打开 motion-prompt 效果库”，选好效果并点击“发送给 AI”即可。

npx skills add rainman016/motion-prompt-zh --skill motion-prompt-zh

让 AI 帮你安装

将下方说明粘贴到 Claude Code 或 Codex，AI 会安装 Skill 并介绍使用方法。

使用方法

  1. 1

    让 AI 打开效果库

    向已安装 motion-prompt-zh Skill 的 AI 说“打开 motion-prompt 效果库”，即可在浏览器中打开本页。

  2. 2

    边预览，边选择

    点击所需效果上的“选择”，支持多选。所选内容会出现在屏幕下方，也可添加“用于开场标题”等简短备注。

  3. 3

    发送给 AI，再提出需求

    点击“发送给 AI”，然后回到对话中说“按这些效果修改视频开场”。该按钮在 AI 通过 Skill 打开效果库时显示。

可以这样提需求

无需记住名称或编号。不确定效果名称时，就像查词典一样，让 AI 打开效果库。

  • 打开 motion-prompt 效果库
  • 有哪些镜头运动？打开列表让我选
  • （选好并发送后）用这些效果修改视频开场

未安装 Skill，或已知编号时

点击下方“复制所选”，把带演示和规格链接的文字粘贴给 AI。只用一个效果时，也可在详情中点击“复制 Prompt”。

已知编号时可直接说：“使用 motion-prompt 的 #012 和 #045。”
